## 📌 Project Overview

Raw e-commerce data is rarely analysis-ready. This project covers the full EDA workflow: inspecting and cleaning the raw data, then exploring sales trends, product performance and customer behaviour through statistics and visualizations.

After cleaning, the dataset contains **138,116 orders**.

## 🎯 Objectives

- Clean and prepare raw e-commerce sales and customer data
- Understand overall sales performance and revenue trends over time
- Identify top-performing products, categories and regions
- Analyze customer behaviour and purchasing patterns
- Present findings with clear visualizations
